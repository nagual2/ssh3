## R5. Взаимодействие с nginx + ротация сертификатов

- Проверить проксирование QUIC через nginx.
- Технический нюанс: nginx умеет (а) UDP stream proxy — L4 без терминации TLS, (б) HTTP/3-терминацию для своего веб-трафика, но не умеет быть HTTP/3-клиентом к бэкенду. Схема «клиент→nginx сертификат A, nginx→ssh3 сертификат B» потребует терминации на nginx — для сырого ssh3-over-h3 это, скорее всего, не взлетит; реалистичный вариант — L4 UDP-прокси с одним серверным сертификатом. Проверить на практике оба сценария.
- Смена сертификата: ротация на сервере (reload/restart), поведение установленных сессий и resume клиентов.
